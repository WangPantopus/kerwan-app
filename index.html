Frequently asked

Is my data really private? What gets sent to the cloud?

Nothing. Kerwan processes all screen data, classification, and search locally on your Mac using SQLite and Ollama. There is no sync service and no telemetry. The only network request Kerwan ever makes is checking for software updates via Sparkle — which you can disable in Settings.

Stripe handles payment processing; Kerwan itself never transmits your captured data anywhere.

What are the Mac requirements? Do I need to install Ollama separately?

Kerwan requires macOS 13 Ventura or later and runs on both Apple Silicon and Intel Macs. For keyword search and time tracking, no AI model is needed.

For AI semantic search and auto-classification, Kerwan uses Ollama running locally. Kerwan will prompt you to install it on first launch if it isn't detected — it's a one-click install and Kerwan manages the model for you.

How is Kerwan different from Toggl, Harvest, or Granola?

Toggl and Harvest require you to remember to start and stop timers. Kerwan captures passively — you never touch a button.

Granola is a meeting notes tool. Kerwan captures your entire work context: browser, apps, documents, and meetings — then connects the dots across all of them.

Most importantly, Kerwan is fully local. Your client conversations never touch someone else's server.
